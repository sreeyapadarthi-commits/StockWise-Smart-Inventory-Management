
# 📦 StockWise – Smart Inventory & Stock Management System

## 📌 Project Overview
StockWise is a simple inventory management application developed using Python, Streamlit, and SQLite. It helps users manage products, monitor stock levels, and calculate inventory value.

## 🎯 Problem Statement
Managing inventory manually can lead to errors, duplicate entries, and difficulty tracking stock levels. StockWise provides a simple digital solution to manage products and monitor low-stock items.

## 🚀 Features
- Add new products
- Prevent duplicate product entries
- Search products
- Update product quantities
- Delete products
- Display inventory dashboard
- Calculate total inventory value
- Low-stock alerts

## 🛠️ Technologies Used
- Python
- Streamlit
- SQLite
- Pandas

## ▶️ How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## 📊 Dashboard
StockWise displays product details, inventory value, and low-stock alerts.
